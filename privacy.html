rclone-personal

Privacy policy

Effective 18 October 2026. This policy describes the personal-use rclone-personal OAuth application operated by Ammar Bardesi for Google Drive backup and verification.

Google data accessed

The application accesses Google Drive files, folder structure and metadata needed to list, compare and copy the folders selected for backup. Google OAuth credentials authorize that access. The source connection uses read-only Drive access. The destination connection needs Drive access to read and create backup files and folders and move earlier destination versions into an archive.

How the data is used and stored

Data is used to run, verify and troubleshoot the operator's backup job. Where supported, Google performs the file copy within Drive. Rclone can process file contents on the operator's computer when needed. Backup copies and archived versions are stored in the operator's Google Drive. Local logs and verification reports can contain file paths, sizes, checks and operational errors.

OAuth tokens and the client configuration are kept in an access-restricted configuration file on the operator's computer. They are not published on this website. Google handles sign-in and authorization.

Disclosure and other uses

This OAuth application uses Google APIs and locally operated rclone. It does not sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models. The public information pages are hosted by GitHub Pages; backup files and OAuth credentials are not uploaded to that website. GitHub may process ordinary website request data under its privacy statement.

The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The backup job preserves copies and previous destination versions until the operator removes them. Local operational records remain until the operator removes them. There is no automatic deletion period promised by this tool.

The account owner can revoke the app's access using Google Account connections. Revoking access prevents subsequent authorized API access; it does not automatically remove files already copied or local records. The operator manages removal of backup copies, archived versions, local logs and credentials.

Contact and changes

For questions or requests about data handled by this tool, contact the operator using the support email shown on its Google consent screen. This page will be updated if the application's data handling changes.
