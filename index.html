rclone-personal

A personal Google Drive backup tool operated by Ammar Bardesi using the open-source rclone application.

This OAuth application lets its operator authorize Google Drive access for copying files from a designated shared folder into the operator's own Drive, preserving older destination versions and checking the copy.

Access and operation

The source connection requests read-only Drive access. The destination connection requests Drive access to copy files, create folders and preserve previous versions. The OAuth scope can cover more of an account than the folders selected in the backup job; the job's folder configuration controls its normal operation.

The tool runs on the operator's computer. Google authentication and consent take place with Google. This informational website does not accept sign-ins, receive OAuth callbacks, or access backup files.

This is a personal-use application for accounts authorized by the operator, with no public sign-up or commercial service.

Privacy policy and data handling

For questions, use the support contact displayed on the application's Google consent screen.
